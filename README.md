# BookSender — книги из папки на Xteink X4 Pro (CrossPoint)

Приложение на Python + Tkinter: сканирует папку с книгами, конвертирует всё
в **EPUB с картинками** через pandoc и само находит читалку в сети, после чего
загружает книги в её библиотеку (папка `/Books` на SD-карте).

Работает на **macOS, Windows и Linux**. Ядро — только стандартная библиотека
Python; Pillow и PyMuPDF (картинки и PDF) ставятся установщиком в локальное
окружение `.venv` и не трогают системный Python.

## Установка с нуля

### 1. Что нужно поставить заранее

| Компонент | Зачем | macOS | Windows | Linux |
|---|---|---|---|---|
| **Python 3.9+** с tkinter | само приложение | python.org или `brew install python` (tkinter входит) | [python.org](https://python.org) — при установке отметьте **tcl/tk and IDLE** | `sudo apt install python3 python3-tk` |
| **pandoc** | fb2/docx/odt/rtf/html/md/txt → EPUB | `brew install pandoc` | [pandoc.org/installing](https://pandoc.org/installing.html) или `choco install pandoc` | `sudo apt install pandoc` |
| Node.js 18+ и git | только для XTC/XTCH (опционально) | `brew install node git` | [nodejs.org](https://nodejs.org) + [git-scm.com](https://git-scm.com) | `sudo apt install nodejs npm git` |
| 7z | архивы `.7z`/`.rar` (опционально; zip умеет сам Python) | `brew install sevenzip` | [7-zip.org](https://www.7-zip.org) | `sudo apt install p7zip-full` |
| Calibre | только mobi/azw3 (опционально; PDF не требует) | `brew install --cask calibre` | [calibre-ebook.com](https://calibre-ebook.com) | `sudo apt install calibre` |

### 2. Установка приложения

```bash
git clone <URL-вашего-репозитория> book-sender
cd book-sender
python setup.py            # создаст .venv, поставит Pillow и PyMuPDF
python setup.py --xtc      # опционально: XTC-конвертер (нужны Node.js и git)
```

`setup.py` сам выбирает Python с tkinter для окружения, скачивает свободный
шрифт PT Serif (OFL, кириллица) для XTC-рендера и при `--xtc` клонирует
[epub-to-xtc-converter](https://github.com/bigbag/epub-to-xtc-converter)
в `vendor/` и ставит его зависимости. Всё локально, в папке проекта.

### 3. Запуск

- **Windows:** двойной клик по `start.bat`
- **macOS / Linux:** двойной клик по `start.command` (или `./start.command`)
- Из терминала: `python book_sender.py` (или `.venv/bin/python book_sender.py`,
  на Windows `.venv\Scripts\python.exe book_sender.py`)

Лаунчеры при **первом запуске сами ставят всё необходимое**: создают `.venv`,
устанавливают Pillow и PyMuPDF, скачивают шрифт и предлагают поставить pandoc
(через пакетный менеджер ОС). Заранее нужен только **Python 3.9+**. Отдельный
запуск `setup.py` не обязателен — он выполняется автоматически; вручную его можно
запустить для пересборки окружения или с `--xtc`.

## Подготовка читалки (единственный ручной шаг)

Веб-сервер CrossPoint работает **только в режиме передачи файлов**:

1. На читалке: **Home → File Transfer → Join Network** (читалка и компьютер
   в одной Wi-Fi сети 2.4 ГГц). Альтернатива: **Create Hotspot** — тогда
   подключите компьютер к сети `CrossPoint-Reader`, адрес `192.168.4.1`.
2. На экране появится IP/QR — адрес можно ввести в приложении вручную,
   но обычно поиск находит устройство сам.
3. После загрузки выключите File Transfer.

## Работа

Выбрать папку с книгами → **Сканировать папку** → **Найти**
(или оставить адрес пустым — поиск выполнится автоматически) →
**Конвертировать и отправить**.

Порядок работы: приложение **сразу конвертирует все книги**, и только потом
подключается к читалке. Если читалка выключена или не в режиме File Transfer —
оно **ждёт и повторяет поиск каждые 5 секунд**, пока она не появится
(или пока не нажмёте «Стоп»). Если IP читалки сменился по DHCP, приложение
найдёт её по новому адресу. Можно включить File Transfer на читалке уже
после запуска конвертации.

### CLI (без GUI, для автоматизации)

```bash
python book_sender.py --find                          # найти читалку в сети
python book_sender.py --cli --folder ~/books --host 192.168.1.50
python book_sender.py --cli --folder ~/books --replace   # с автопоиском, перезапись
python book_sender.py --cli --folder ~/books --wait-timeout 300  # ждать макс. 5 мин
python book_sender.py --cli --folder ~/books --flat   # без папок авторов
python book_sender.py --cli --folder ~/books --lang en   # язык сообщений
```

Без `--wait-timeout` (или с `0`) CLI ждёт появления устройства бесконечно;
прерывание — Ctrl+C.

## Поддерживаемые форматы

| Вход | Что происходит |
|---|---|
| `.fb2` | pandoc → EPUB; картинки и обложка сохраняются, имя файла = «Автор - Название» из метаданных |
| `.fb2.zip`, `.fbz`, `.zip` | распаковка (`.fbz` — так Flibusta отдаёт zip с fb2; в т.ч. имена в cp866), конвертация каждого файла внутри |
| `.7z`, `.rar` | то же, через внешний `7z` |
| `.epub` | копируется как есть (кривые EPUB лечит встроенный EPUB Optimizer на читалке) |
| `.xtc`, `.xtch` | нативные форматы читалки (предварительно отрендеренные страницы) — копируются как есть, открываются без индексации |
| `.docx`, `.odt`, `.rtf`, `.html`, `.md`, `.txt` | pandoc → EPUB (относительные картинки в HTML и md подхватываются; в md работает и base64) |
| `.pdf` | **Всё автоматически.** PDF с текстом → EPUB с картинками (текст и изображения извлекаются PyMuPDF, перенабираются под экран, Calibre не нужен). Сложная вёрстка (2+ колонки текста, таблицы/схемы — по количеству векторной графики, альбомные слайды) и PDF без текста (скан) → XTC рендером страниц с обрезкой белых полей и дизерингом. Ручной выбор XTC/XTCH в колонке «Формат» принудительно включает рендер страниц |
| `.mobi`, `.azw3` | Calibre `ebook-convert`, если установлен; иначе пропускается с сообщением |
| прочее (`.djvu`, `.cbr`, …) | пропускается с сообщением |

Повторный запуск безопасен: приложение рекурсивно проверяет `/Books` **вместе
со всеми вложенными папками** и пропускает уже загруженные файлы (в т.ч.
разложенные плагином organize-by-author по авторам). Режим «Перезаписывать»
перезаписывает атомарно; если старая копия лежит в другой папке — она удаляется.

**Раскладка по авторам** (включена по умолчанию, галочка в GUI / `--flat` в CLI
для отключения): книга загружается сразу в папку автора, например
`/Books/Фамилия Имя/Фамилия Имя - Название книги.epub`. Автор читается из OPF готового
EPUB ровно так же, как это делает плагин
[organize-by-author](https://github.com/itsthisjustin/sd-plugins)
(file-as → текст первого dc:creator, та же очистка имени, лимит 60 символов),
поэтому папки совпадают с созданными плагином. Книги без автора остаются в корне.

FB2 в **cp1251** автоматически перекодируются в UTF-8 перед конвертацией
(pandoc иначе превращает текст в кракозябры).

**Оптимизация EPUB перед отправкой** (включена по умолчанию; галочка в GUI,
`--no-optimize` в CLI). Встроенный оптимизатор CrossPoint — ручной инструмент
(на устройстве и в веб File Manager), при загрузке он НЕ запускается. BookSender
делает его базовые шаги заранее, чистым Python:

- защитный CSS в каждый XHTML (как в оптимизаторе прошивки: `img{max-width:100%}`,
  переносы, фиксированные таблицы — чтобы книга не вылезала за экран);
- удаление встроенных шрифтов: файлы, записи в манифесте, `@font-face` в CSS
  (включая data: URI), записи в `encryption.xml` — CrossPoint их не использует,
  это 100 КБ–2 МБ мертвого веса на книгу;
- снятие атрибутов `width`/`height` у `<img>`.

Обработка картинок делается через Pillow (ставится установщиком в `.venv`;
без Pillow картинки остаются как есть):

- **оттенки серого с сохранением всех 256 уровней** (не чёрно-белый 1-bit!
  цвет экрану не нужен, а полутона важны);
- вписывание в экран **800×480** без увеличения (мелкий декор <20px не трогается);
- прозрачность → белый фон;
- пережатие: baseline JPEG 85% (e-ink не понимает progressive JPEG), PNG optimize.

Также вычищается «вредный» для e-ink CSS (`float`, `position: fixed/absolute`,
`display: flex/grid`) в файлах и inline-стилях, удаляются HTML-комментарии —
как в оптимизаторах [bigbag/epub-to-xtc-converter](https://github.com/bigbag/epub-to-xtc-converter)
и прошивки. Тяжёлые операции веб-оптимизатора (разрезание картинок
под листание, поворот, автообрезка полей) не портированы — они специфичны
для режима листания устройства.

## Как это работает внутри

- Поиск: официальный UDP-поиск CrossPoint (`hello` → порт 8134), затем
  mDNS `crosspoint.local`, затем сканирование подсети /24 с проверкой
  `GET /api/status`.
- Загрузка: `POST /upload?path=/Books` (multipart), папка создаётся через
  `POST /mkdir`, список существующих файлов — `GET /api/files`.
  Загрузка книги помечает индекс библиотеки — книга появится при следующем
  открытии Library на устройстве.
- Конвертация: `pandoc -f fb2 -t epub --epub-cover-image …`; обложка
  извлекается из `<coverpage>` FB2. Имена файлов чистятся под FAT32.

Протокол: [docs/webserver-endpoints.md](https://github.com/crosspoint-reader/crosspoint-reader/blob/develop/docs/webserver-endpoints.md).

## Индексация на читалке: можно ли заранее?

CrossPoint строит два кэша:

- **индекс библиотеки** — пересобирается при открытии Library после изменений файлов;
- **кэш книги** `/.crosspoint/epub_<hash>/`: `book.bin` (метаданные, spine, TOC) и
  `section.bin` (переносы строк, позиции слов, страницы).

Кэш книги **нельзя надёжно построить заранее на компьютере**: он считается
рендерером читалки с её шрифтами и настройками (шрифт, размер, поля, интервалы —
всё это входит в ключ кэша), а версия формата часто меняется (`section.bin`
уже v74, в [истории](https://github.com/crosspoint-reader/crosspoint-reader/blob/develop/docs/file-formats.md)
десятки перестроений). Любая смена настроек или обновление прошивки сбрасывает кэш.
Кроме того, кэш очищается при **каждой загрузке/перемещении/переименовании** книги —
после массовой перевыкладки читалка проиндексирует книги при первом открытии,
это нормально и происходит один раз.

Если нужно, чтобы книги открывались **мгновенно без индексации**, — конвертируйте
их заранее в **XTC/XTCH**: нативный формат читалки с уже отрендеренными страницами,
индексом страниц и оглавлением. Инструмент:
[bigbag/epub-to-xtc-converter](https://github.com/bigbag/epub-to-xtc-converter)
([веб-версия](https://liashkov.site/epub-to-xtc-converter/), Node CLI).
Компромисс: фиксированная вёрстка — шрифт и размер «зашиваются» при конвертации
и на устройстве не меняются. Готовые `.xtc`/`.xtch` кладите в папку с книгами —
BookSender отправит их как есть.

Можно и наоборот: выбрать в BookSender формат **XTC/XTCH** для отдельных книг
(клик по колонке «Формат» в списке: EPUB → XTC (ч/б) → XTCH (серые страницы),
или выделить строки и применить формат из панели) — приложение само
сконвертирует оптимизированный EPUB в XTC. Нужен конвертер: `python setup.py --xtc`
(или двойной клик по `setup_xtc.command` / `setup_xtc.bat`).

Размер шрифта XTC выбирается как в прошивке — **в pt (12/14/16/18)** комбобоксом
«Шрифт XTC (pt)», который появляется только когда выбран XTC/XTCH (CLI:
`--xtc-font-pt`, по умолчанию 14). Внутри pt переводятся в пиксели экрана
(14pt ≈ 42px). Внимание: чем крупнее шрифт, тем больше страниц и файл (каждая
страница — несжатый битмап ~48 КБ; замеры на романе среднего объёма: 14pt → ~130 МБ,
EPUB → 392 КБ). В BookSender встроен локальный патч бага конвертера (upstream
применяет настройки шрифта ПОСЛЕ загрузки книги, из-за чего размер
игнорировался и страницы ломались); патч применяется автоматически.

## Языки интерфейса

Русский, English, 中文. Язык определяется автоматически по системному
(LC_ALL/LANG, на macOS — AppleLanguages); явно выбрать можно комбобоксом
«Язык» в окне приложения (переключение живое, список файлов сохраняется)
или флагом CLI `--lang ru|en|zh` (`--lang auto` — по системе).
Выбор запоминается в настройках.

Это настоящая многоязычность, а не перебор: переводы лежат в
`locales/<код>.json` (плоский словарь ключ → строка, `_name` — самоназвание).
**Добавление нового языка = новый JSON-файл** — он сам появится в селекторе,
код менять не нужно. Отсутствующий ключ откатывается на английский,
затем на сам ключ. Подстановки — `{name}`, `{ip}` и т.п.

## Ограничения и советы

- **PDF** — слабое место: конвертация в EPUB теряет вёрстку, сканам нужен OCR.
  Для технической литературы X4 Pro в принципе не лучший экран.
- Сервер читалки без пароля — используйте только доверенную сеть.
- Если поиск не находит устройство: проверьте, что File Transfer включён,
  сеть общая (гостевая Wi-Fi изолирует клиентов), и введите IP с экрана вручную.
- Настройки (папка, адрес, режим, язык) сохраняются в `book_sender_settings.json`.

```bash
python tests/selftest.py
```

Тест создаёт учебные FB2/ZIP/7Z/PDF, поднимает локальный mock-сервер CrossPoint
и прогоняет весь конвейер: картинки внутри EPUB, cp1251/cp866, PDF-маршрутизацию,
XTC-выбор, многоязычность и факт загрузки.
