# BookSender — книги из папки на Xteink X4 Pro (CrossPoint)

Кладёте книги (fb2, pdf, docx, epub — что угодно из списка ниже) в папку,
жмёте одну кнопку — приложение конвертирует всё в EPUB и само находит
читалку в сети, загружая книги в её библиотеку.

Работает на **macOS, Windows и Linux**.

## Установка

| Нужно заранее | Зачем |
|---|---|
| **Python 3.9+** (с tkinter) | само приложение |
| **pandoc** | конвертация книг в EPUB |

| Устанавливается автоматически при первом запуске | |
|---|---|
| Pillow | обработка картинок |
| PyMuPDF | чтение PDF |
| PT Serif | шрифт для XTC-рендера |

- **Windows:** двойной клик по `start.bat`
- **macOS / Linux:** двойной клик по `start.command` (или `./start.command`)

При первом запуске лаунчер сам создаёт окружение и ставит зависимости —
ничего вручную ставить не нужно. Pandoc предлагается установить автоматически
(через пакетный менеджер вашей ОС); при отказе — [
инструкция](https://pandoc.org/installing.html).

Опционально — XTC-конвертер (мгновенное открытие книг, см. ниже):
`python setup.py --xtc` (нужны Node.js 18+ и git).

## Подготовка читалки (единственный ручной шаг)

Веб-сервер CrossPoint работает **только в режиме передачи файлов**:

1. На читалке: **Home → File Transfer → Join Network** (читалка и компьютер
   в одной Wi-Fi сети 2.4 ГГц). Альтернатива: **Create Hotspot** — тогда
   подключите компьютер к сети `CrossPoint-Reader`, адрес `192.168.4.1`.
2. На экране появится IP/QR — адрес можно ввести в приложении вручную,
   но обычно поиск находит устройство сам.
3. После загрузки выключите File Transfer.

## Работа

Выбрать папку с книгами → **Сканировать папку** → **Найти**
(или оставить адрес пустым — поиск выполнится автоматически) →
**Конвертировать и отправить**.

Приложение **сразу конвертирует все книги**, и только потом подключается
к читалке. Если читалка выключена или не в режиме File Transfer — оно **ждёт
и повторяет поиск каждые 5 секунд**, пока она не появится (или пока не нажмёте
«Стоп»). Если IP сменился — найдёт по новому адресу. Можно включить
File Transfer уже после запуска конвертации.

Папка с книгами наблюдается постоянно: **новые и изменённые файлы появляются
в списке сами**, сверху списка (самые свежие первыми) — кнопку «Сканировать
папку» нажимать не нужно.

Можно отправить и только часть списка: выделите нужные строки
(Cmd/Shift+клик) и нажмите «Конвертировать и отправить» — обработаются
только они. Без выделения отправляются все.

Клик по строке показывает **обложку книги** в панели справа от списка
(FB2, FB2 внутри zip/fbz, EPUB; для PDF — первая страница) вместе
с названием и автором из метаданных.

Повторный запуск безопасен: уже загруженные книги пропускаются (в том числе
разложенные по авторам). Режим «Перезаписывать» заменяет старые копии.
**Дубликаты пропускаются автоматически**: файлы с одинаковым содержимым
(даже под разными именами и в разных подпапках) не конвертируются
и не отправляются — остаётся первая копия. Разные форматы одной книги
(например, fb2 и epub) дубликатами не считаются.

### Браузер читалки

Когда читалка найдена в сети, рядом с кнопками появляется **«Браузер читалки»**
(офлайн кнопка скрыта). Присутствие читалки в сети проверяется автоматически
**каждые 5 секунд** (известный адрес + UDP-поиск CrossPoint): кнопка появляется
и исчезает сама, смена IP подхватывается. Окно показывает файлы в папке
назначения (`/Books` по умолчанию) со всеми подпапками и размерами:

- **«✓ есть»** — книга есть в локальном каталоге (совпадение по имени,
  под которым она отправляется). Обложка такой книги берётся из локального
  файла — скачивать с читалки ничего не нужно.
- Книги, которых нет в каталоге: обложка EPUB **скачивается с читалки
  автоматически** (файлы до 30 МБ); у XTC/TXT обложки нет.
- **Удаление**: выделите файлы (Cmd/Shift+клик) → «Удалить с читалки» →
  подтверждение. Удаляются только выбранные файлы; действие необратимо.

Список обновляется кнопкой «Обновить» и сам после каждой отправки;
отметки «есть» пересчитываются при изменении локального каталога.

### CLI (для автоматизации)

```bash
python book_sender.py --find                          # найти читалку в сети
python book_sender.py --cli --folder ~/books --host 192.168.1.50
python book_sender.py --cli --folder ~/books --replace   # с автопоиском, перезапись
python book_sender.py --cli --folder ~/books --wait-timeout 300  # ждать макс. 5 мин
python book_sender.py --cli --folder ~/books --flat   # без папок авторов
python book_sender.py --cli --folder ~/books --lang en   # язык сообщений
python book_sender.py --cli --folder ~/books --ascii-symbols   # стрелки -> ASCII
```

Без `--wait-timeout` (или с `0`) CLI ждёт появления устройства бесконечно;
прерывание — Ctrl+C.

## Поддерживаемые форматы

| Вход | Что происходит |
|---|---|
| `.fb2` | → EPUB; картинки и обложка сохраняются, имя файла = «Автор - Название» из метаданных |
| `.fb2.zip`, `.fbz`, `.zip` | распаковка и конвертация каждого файла внутри |
| `.7z`, `.rar` | то же, через внешний `7z` |
| `.epub` | оптимизируется под экран (см. ниже) |
| `.xtc`, `.xtch` | нативный формат читалки — открывается мгновенно, без индексации |
| `.docx`, `.odt`, `.rtf`, `.html`, `.md`, `.txt` | → EPUB (картинки из документа переносятся) |
| `.pdf` | **автоматически:** с текстом → EPUB с картинками; сканы и сложная вёрстка (колонки, таблицы, слайды) → XTC страницами |
| `.mobi`, `.azw3` | через Calibre, если установлен; иначе пропускается |
| `.djvu` | → XTC страницами (рендер ddjvu; нужен [DjVuLibre](https://djvu.sourceforge.net): macOS `brew install djvulibre`, Linux `sudo apt install djvulibre-bin`, Windows — установщик DjVuLibre) |
| прочее (`.cbr`, …) | пропускается с сообщением |

## Что делает с книгами

- **Раскладка по папкам авторов** (включена по умолчанию; `--flat` — отключить):
  книга ложится в `/Books/Автор/`, как при сортировке плагином на читалке.
  Книги без автора остаются в корне.
- **Пропуск уже загруженного**: `/Books` проверяется со всеми подпапками,
  повторный запуск ничего не задваивает. Режим «Перезаписывать» заменяет
  старые копии (даже из другой папки).
- **Пропуск дубликатов по содержимому** (всегда, без настройки): одинаковые
  файлы под разными именами не конвертируются и не отправляются повторно.
- **Оптимизация EPUB** (включена по умолчанию; `--no-optimize` — отключить):
  - защитный CSS, чтобы книга не вылезала за экран 480×800;
  - удаление встроенных шрифтов (читалка их не использует — экономия до 2 МБ);
  - картинки → **оттенки серого**, вписывание в экран **800×480**, пережатие;
  - **ремонт структуры**: восстанавливаются `mimetype` и `META-INF/container.xml`,
    если отсутствуют или повреждены;
  - **проверка структуры**: битые EPUB не отправляются;
  - опционально — **замена редких символов**: стрелки и галочки, которых нет
    в шрифтах читалки (`→` `⇒` `✓`), заменяются на ASCII (`->` `=>` `v`) —
    галочка «Заменять редкие символы» или `--ascii-symbols`. Альтернатива —
    шрифты с этими символами: приложение **само загружает их на читалку** при
    подключении и при смене языка интерфейса — **Gentium Book Plus** (русский),
    **Charis SIL** (английский), **Noto Serif SC / 思源宋体** (китайский).
    Остаётся выбрать шрифт в Settings > Reader > Font Family.
- FB2 в кодировке cp1251 автоматически перекодируются в UTF-8.

## Мгновенное открытие: XTC и XTCH

Это нативный формат читалки: страницы уже отрендерены, книга открывается
сразу, без индексации. Обратная сторона — вёрстка фиксированная: шрифт и
размер выбираются при конвертации и на устройстве не меняются.

| | **XTC** | **XTCH** |
|---|---|---|
| Пиксель | 1 бит: чёрный/белый | 2 бита: 4 уровня серого |
| Полутона | дизеринг | плавнее, лучше для картинок |
| Размер страницы | ~47 КБ | ~94 КБ |

- **XTC** — для текстовых книг (файл вдвое меньше).
- **XTCH** — для книг с картинками (серые уровни плавнее).
- Размер шрифта — в pt, как на читалке (12/14/16/18); поле появляется,
  когда выбран XTC/XTCH. Крупнее шрифт — больше страниц и файл
  (страница — несжатый битмап ~48 КБ; роман при 14pt ≈ 130 МБ).

Включить: клик по колонке «Формат» в списке (EPUB → XTC → XTCH) или выделить
строки и применить формат из панели. Нужен конвертер: `python setup.py --xtc`
(или двойной клик по `setup_xtc.command` / `setup_xtc.bat`). Готовые `.xtc`
можно просто положить в папку с книгами.

## Языки интерфейса

Русский, English, 中文. Определяется автоматически по системе; можно выбрать
комбобоксом «Язык» (переключение живое, список книг сохраняется) или флагом
CLI `--lang ru|en|zh`. Выбор запоминается.

## Ограничения и советы

- **PDF** — слабое место: перенабор теряет вёрстку, сканам нужен OCR
  (или используйте режим XTC — страницы как есть). Для технической
  литературы X4 Pro в принципе не лучший экран.
- Сервер читалки без пароля — используйте только доверенную сеть.
- Если поиск не находит устройство: проверьте, что File Transfer включён,
  сеть общая (гостевая Wi-Fi изолирует клиентов), и введите IP с экрана вручную.
- Настройки (папка, адрес, режим, язык) сохраняются между запусками.
